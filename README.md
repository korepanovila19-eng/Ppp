# Shop Mod (Fabric 1.20.1)

Серверный мод: работает на сервере БЕЗ клиентского мода, а также в одиночном мире.
Нужен только Fabric Loader + Fabric API (на сервере / в клиенте для одиночной игры).

Команды: /shop, /sellitems, /balance, /money give <игрок> <сумма> (оп).

## Как получить .jar

### Вариант А: GitHub (можно с телефона)
1. Создай репозиторий на github.com, загрузи в него все файлы проекта (включая папку .github).
2. Вкладка Actions -> build -> Run workflow (или просто после загрузки запустится сам).
3. Когда сборка зелёная - открой её, внизу Artifacts -> shopmod-jar -> скачай, распакуй, внутри shopmod-1.0.0.jar.

### Вариант Б: на ПК
Нужны JDK 17 и Gradle 8.5+:  `gradle build`  -> jar в build/libs/shopmod-1.0.0.jar

## Установка
Положи jar в папку mods (сервер или клиент) вместе с Fabric API 0.92.2+1.20.1.

## Настройка
- Награды за мобов: Rewards.java
- Цены продажи системе: Prices.java
- Лимит лотов на игрока: Market.MAX_LISTINGS
